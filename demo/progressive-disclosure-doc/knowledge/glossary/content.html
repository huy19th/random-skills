Terms

cache

A local store of received responses, plus the subsystem that controls storing, retrieving and deleting them.

Its purpose is to answer equivalent future requests faster and with less bandwidth.

origin server

The server that generates the response, and that a cache asks when it needs to check whether a stored response is still usable.

Example: the application server behind a CDN. The CDN is the cache, the application server is the origin. Inference

private cache

A cache serving a single user, e.g. the browser cache.

Usually part of the user agent (browser, app).

shared cache

A cache that stores responses for reuse by many users, e.g. a CDN or proxy.

Usually sits on an intermediary between users and the server.

Because it is shared, a shared cache must not store a response meant for one user (see the private directive).
