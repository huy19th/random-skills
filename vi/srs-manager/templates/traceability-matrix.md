# Traceability Matrix

Nguồn sự thật (source of truth) để tra: requirement nào implement ở đâu, test ở đâu, trạng thái ra sao.
Luôn cập nhật đồng thời với file SRS module tương ứng — đừng để 2 nơi lệch nhau.

| Req ID | Mô tả ngắn | File/Module | Method/Function | Test file | Status |
|---|---|---|---|---|---|
| REQ-AUTH-001 | {mô tả} | `src/...` | `functionName()` | `tests/...` | Draft |
